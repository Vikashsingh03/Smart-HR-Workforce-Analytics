# Data

No data files are stored in this repo.

**Primary dataset:** IBM HR Analytics Employee Attrition and Performance — 1,470 employee records, 35 columns.

Download it from Kaggle (free account needed):
https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset

The raw CSV must be stored unchanged and never edited. Every later step reads from that raw file.

A small supplementary attendance/leave feed is planned as a demo API (Node/Express, local) — see `docs/architecture.md`. No real employee personal data is used anywhere in this project.
